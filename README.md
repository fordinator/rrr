## Preamble

**Retro Revels Rewind** (hereafter referred to as _RRR_) is a _Wabbajack_ modlist for _Skyrim Legendary Edition_.

The theme is very "rigid." It focuses heavily on mods that had been released **pre-2014**, particularly _Lover's Lab_ mods designed for submissive female player characters, with assorted patching and script improvements.

### System Requirements

Any modern PC should handle _RRR_ well.

However, the more powerful your CPU, the faster the scripting would be. 

It is not recommended to use this modlist on a system current as of the time period which it was designed around!

### Acquiring Skyrim

This modlist is a "nostalgic throwback", intended for those who *purchased Skyrim when it was originally released.*

There are no official means to acquire the game as of 2026, acquiring the game new is not recommended, and thus no instructions to that end will be provided.

If you acquire the game by other means, that is your concern.

### Installation

Make certain your *Skyrim* installation is clean.

Start the game once, to populate the `.ini` files via the Launcher.

Create a directory for *Wabbajack*, preferably at the root of a non-Operating System drive.

Create a directory for *RRR*, same deal. The `downloads` folder will be within this directory.

Create *antivirus* exceptions for your *Skyrim* directory, the *Wabbajack* directory, and the *RRR* directory. *Windows Defender* is a form of antivirus that is included with *Windows.*

Ensure that *OneDrive* is either uninstalled, shut down, or disabled for the *Documents* folder.

Although *Wabbajack* provides **LIMITED** support for manual downloads from *Lover's Lab* (and other non-*Nexus* sources), it is **FIERCELY RECOMMENDED** to download all such files beforehand, and place them in the Downloads directory by hand.

Download and launch the *Wabbajack* app.

Login to *Nexus* and *Lover's Lab* via the *Wabbajack* app.

Find and begin the installation of *RRR* via the *Wabbajack* UI.

### MCM Configuration

This modlist has a slightly different *MCM configuration* than most NSFW lists.

Be sure to wait until all messages appear and disappear in the upper left corner of the screen. There are a lot of them, and *Legendary Edition* is much slower to process them than *Special Edition*.

Enable *SexLab* as normal, but **DO NOT** register any animations for the mod in the **SLAL.** This will be done **AFTER** the *MCM Recording*. Exit the *MCM* and wait for all messages to stop again. Enable Creature Support in the *SexLab MCM* if desired, there is one more message to wait on if you do.

Open the *ZAZ 8* MCM, navigate to the *SexLab* section, and *Register Animations*. Wait for the popup before closing the menu.

Enable the *Apropos* mod. Only takes a few seconds.

Now run the *MCM Recording* called *RRR*. This configures the modlist, and enables **only** the recommended set of NSFW animations. 

Enable *SL Defeat* and Load the settings in the *MCM* menu.

Finally, open the *SL Animation Loader MCM Menu* and "Register All." It takes a long time, so be patient for the popup before closing the window.

You're ready to go!

### The Alternate Start

One of my persistent complaints about Alternate Start mods is that you always have to go to Helgen early anyway, or many quests will be unavailable. So this modlist places you at the exit of Helgen Cave with all important quest triggers cleared -- you are free to go wherever you wish from the very beginning. The primary difference is that you are buck naked, have no gear, and no starting spells beyond your Racial Abilities. You do still get to select whom you escaped with (Hadvar or Ralof)

For my personal amusement, I have included three `YES/NO` popup options.

`Do you wish to start as a slave?` will immediately begin the *Simple Slavery* mod with the MCM option *Enslave Me Now!*

`Do you wish to be teleported to a random location?` will teleport you to one of the many `coc` markers throughout the *Skyrim* overworld, randomly determined.

`Would you like a set of HILARIOUS bondage gear?` will equip you with a BDSM set of gear with an amusing appearance and powerful abilities.

Answer 'no' to all options and you run to Riverwood with Hadvar or Ralof.
